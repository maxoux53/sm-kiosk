## Technologies utilisées

### Frontend

#### Web

- React
- Vite
- [PicoCSS](https://github.com/picocss/pico)

#### Mobile

- React Native
- Expo

### Backend

- Node.js
- Express
- Prisma ORM

### Base de données

- PostgreSQL

### Modélisation

- Draw.io (entité-association et relationnel)
